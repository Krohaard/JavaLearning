Interfaces en Java

Concept d'Interface

Une interface en Java est une référence de type, similaire à une classe, qui peut contenir uniquement des méthodes abstraites et des constantes. Les interfaces sont utilisées pour spécifier un comportement que les classes implémentant l'interface doivent suivre.

Pour plus d'informations, consultez la documentation officielle.

Déclaration d'une Interface

Exemple 1 : Déclaration d'une interface simple.

interface Animal {
    // Méthode abstraite
    void faireDuBruit();

    // Constante
    String TYPE = "Animal";
}

Implémentation d'une Interface

Exemple 2 : Implémentation de l'interface par une classe.

class Chien implements Animal {
    // Implémentation de la méthode abstraite
    public void faireDuBruit() {
        System.out.println("Le chien aboie.");
    }
}

class Main {
    public static void main(String[] args) {
        Chien monChien = new Chien();
        monChien.faireDuBruit(); // Affiche : Le chien aboie.
    }
}

Fonctions Utiles

Méthodes d'Interface :

  • default : Permet de fournir une implémentation par défaut pour une méthode dans une interface.
  • static : Permet de définir une méthode statique dans une interface.
