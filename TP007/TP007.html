Exercice 7 : Gestion des fichiers

1. Cours explicatif

Objectif : Comprendre les bases de la gestion des fichiers en Java.

Java propose plusieurs classes pour travailler avec des fichiers. Voici les principales :

  • File : Représente un fichier ou un répertoire, permet de vérifier son existence, sa taille, etc.
  • FileWriter : Utilisé pour écrire du texte dans un fichier.
  • FileReader : Utilisé pour lire du texte depuis un fichier.
  • BufferedReader et BufferedWriter : Fournissent une lecture et une écriture plus efficaces grâce au buffering.

Exemple simple d'écriture dans un fichier

import java.io.FileWriter;
import java.io.IOException;

public class Exemple {
    public static void main(String[] args) {
        try (FileWriter writer = new FileWriter("exemple.txt")) {
            writer.write("Bonjour, fichier !");
        } catch (IOException e) {
            System.out.println("Erreur : " + e.getMessage());
        }
    }
}

Exemple simple de lecture depuis un fichier

import java.io.FileReader;
import java.io.BufferedReader;
import java.io.IOException;

public class Exemple {
    public static void main(String[] args) {
        try (BufferedReader reader = new BufferedReader(new FileReader("exemple.txt"))) {
            String ligne;
            while ((ligne = reader.readLine()) != null) {
                System.out.println(ligne);
            }
        } catch (IOException e) {
            System.out.println("Erreur : " + e.getMessage());
        }
    }
}

Pour plus d'informations, consultez la documentation officielle.

2. Énoncé

  1. Écris un programme qui :
    • Crée un fichier texte nommé "resultat.txt".
    • Écrit les 10 premières lignes de la table de multiplication choisie par l'utilisateur dans ce fichier.
    • Lit le contenu du fichier et l'affiche dans la console.
  2. Gère les erreurs éventuelles (fichier inaccessible, saisie invalide, etc.).

3. Exemple attendu

Entrez un nombre pour la table de multiplication : 5
Fichier "resultat.txt" créé et rempli.

Contenu du fichier :

5 x 10 = 50
