Exercice 2 : Calcul et affichage conditionnel

Objectif : Approfondir les conditions (if, else if, else) et les opérateurs mathématiques.

Énoncé

  1. Écris un programme qui :
    • Demande à l'utilisateur :
      • Deux nombres décimaux (ex. 12.5 et 8.3).
    • Propose les options suivantes :
      • Addition
      • Soustraction
      • Multiplication
      • Division
    • En fonction du choix de l'utilisateur, effectue l'opération correspondante et affiche le résultat.
    • Gère les cas où l'utilisateur :
      • Tente de diviser par zéro (affiche un message d'erreur).
      • Entre une option invalide (affiche un message d'erreur).

Exemple attendu

Entrez le premier nombre : 12.5
Entrez le deuxième nombre : 8.3
Choisissez une opération (1=Addition, 2=Soustraction, 3=Multiplication, 4=Division) : 1
Résultat : 20.8

Conseils techniques

  • Utilise un switch pour simplifier les choix d'opération.
  • Garde en tête qu'une division par zéro génère une erreur qu'il faut gérer avec une condition.
  • Exemple d ’utilisation de switch : 
    switch (choix) {
    case 1:
        // Addition
        break;
    case 2:
        // Soustraction
        break;
    default:
        // Message d'erreur
}
