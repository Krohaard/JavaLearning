Collections et Structures de Données en Java

Introduction aux Collections

Les collections en Java sont des structures de données qui permettent de stocker et de manipuler des groupes d'objets. Elles sont définies dans le package java.util.

Pour plus d'informations, consultez la documentation officielle.

Types de Collections

  • List : Une collection ordonnée qui peut contenir des doublons (par exemple, ArrayList).
  • Set : Une collection non ordonnée qui ne peut pas contenir de doublons (par exemple, HashSet).
  • Map : Une collection d'associations clé/valeur (par exemple, HashMap).

Exemples

Exemple 1 : Utilisation d'une ArrayList.

import java.util.ArrayList;

public class ExempleListe {
    public static void main(String[] args) {
        ArrayList<String> liste = new ArrayList<>();
        liste.add("Pomme");
        liste.add("Banane");
        liste.add("Cerise");

        for (String fruit : liste) {
            System.out.println(fruit);
        }
    }
}

Exemple 2 : Utilisation d'un HashSet.

import java.util.HashSet;

public class ExempleSet {
    public static void main(String[] args) {
        HashSet<String> ensemble = new HashSet<>();
        ensemble.add("Chat");
        ensemble.add("Chien");
        ensemble.add("Chat"); // Doublon, ne sera pas ajouté

        for (String animal : ensemble) {
            System.out.println(animal);
        }
    }
}

Exemple 3 : Utilisation d'un HashMap.

import java.util.HashMap;

public class ExempleMap {
    public static void main(String[] args) {
        HashMap<String, Integer> map = new HashMap<>();
        map.put("Un", 1);
        map.put("Deux", 2);
        map.put("Trois", 3);

        for (String clé : map.keySet()) {
            System.out.println(clé + " : " + map.get(clé));
        }
    }
}

Fonctions Utiles

Méthodes de Collection :

  • add(E e) : Ajoute un élément à la collection.
  • remove(Object o) : Supprime un élément de la collection.
  • size() : Retourne le nombre d'éléments dans la collection.
