Exercice 9 : Classes et Objets en Java

1. Cours explicatif

Objectif : Comprendre comment utiliser les classes et les objets pour structurer un programme en Java.

Concepts abordés

  • Classe : Une classe est un plan ou modèle qui définit les propriétés et comportements d'un type d'objet.
  • Objet : Une instance d'une classe, créée à partir de celle-ci.
  • Attributs : Les variables membres d'une classe (représentent ses propriétés).
  • Méthodes : Les fonctions membres d'une classe (représentent ses comportements).

Exemple simple

public class Person {
    String name;
    int age;

    // Constructeur
    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    // Méthode
    public void introduce() {
        System.out.println("Bonjour, je m'appelle " + name + " et j'ai " + age + " ans.");
    }
}

public class Main {
    public static void main(String[] args) {
        Person person = new Person("Alice", 30); // Création d'un objet
        person.introduce(); // Appel d'une méthode
    }
}

2. Énoncé

Écris un programme qui :

  1. Crée une classe Rectangle avec :
    • Deux attributs : largeur et hauteur (entiers).
    • Un constructeur pour initialiser ces attributs.
    • Deux méthodes :
      • calculerAire() : Renvoie l'aire du rectangle.
      • calculerPerimetre() : Renvoie le périmètre du rectangle.
  2. Dans la méthode main, demande à l'utilisateur d'entrer les dimensions d'un rectangle.
  3. Crée un objet Rectangle avec les dimensions saisies.
  4. Affiche l'aire et le périmètre du rectangle.

3. Exemple attendu

Entrez la largeur du rectangle : 5
Entrez la hauteur du rectangle : 10
Aire : 50
Périmètre : 30

4. Conseils techniques

  • Utilise des méthodes pour encapsuler les calculs d'aire et de périmètre.
  • Déclare tes attributs comme privés et utilise des getters si nécessaire.
  • Teste avec différentes dimensions pour vérifier le programme.

5. Temps estimé pour un développeur expert

Environ 20 à 30 minutes.
