Exercice 14 : Gestion d’un Système de Commandes

1. Objectif

Créer un programme permettant de gérer un système de commandes en ligne, en utilisant des classes et des collections.

2. Énoncé

Écrivez un programme en Java qui :

  1. Crée une classe Produit avec :
    • id (int)
    • nom (String)
    • prix (double)
    • stock (int)
  2. Crée une classe Commande avec :
    • id (int)
    • liste de produits (Map<Produit, Integer> où la clé est le produit et la valeur est la quantité).
    • statut (String) : "En attente", "Expédiée", "Livrée".
    • Méthodes pour ajouter un produit, calculer le total et modifier le statut.
  3. Crée une classe GestionCommandes qui permet :
    • Créer une commande.
    • Ajouter des produits à une commande.
    • Modifier le statut d'une commande.
    • Afficher toutes les commandes.
  4. Implémente un menu permettant à l’utilisateur de gérer le système de commandes.

4. Conseils techniques

  • Utilisez une ArrayList pour stocker les commandes.
  • Stockez les produits d’une commande avec une HashMap (clé : produit, valeur : quantité).
  • Assurez-vous que les stocks sont mis à jour lors d’une commande.

5. Concepts abordés

  • Utilisation des collections pour gérer les produits et commandes.
  • Gestion des interactions utilisateur avec un menu.
  • Encapsulation et manipulation des objets avec des méthodes.

6. Temps estimé

Un développeur expert mettrait environ 1h à 1h30 pour résoudre cet exercice.
