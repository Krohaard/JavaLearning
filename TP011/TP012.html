Exercice 12 : Gestion d'une bibliothèque

1. Objectif

Créer une application permettant de gérer les livres d'une bibliothèque. Cet exercice combine l'utilisation des classes et des collections pour modéliser un système de gestion de livres.

2. Énoncé

Écrivez un programme en Java qui :

  1. Crée une classe Livre avec les attributs suivants :
    • titre (String)
    • auteur (String)
    • annéePublication (int)
    • disponible (boolean)
  2. Crée une classe Bibliotheque avec :
    • Une collection (ArrayList) pour stocker les livres.
    • Des méthodes pour :
      • Ajouter un livre.
      • Rechercher un livre par titre.
      • Afficher la liste des livres disponibles.
      • Emprunter un livre (le marquer comme non disponible).
      • Retourner un livre (le marquer comme disponible).
  3. Dans la méthode main, crée une instance de la classe Bibliotheque et interagit avec l'utilisateur pour ajouter, emprunter ou retourner des livres.

4. Conseils techniques

  • Utilisez une boucle pour afficher le menu principal et permettre plusieurs actions utilisateur.
  • Ajoutez des validations (ex. : vérifier si un livre existe avant de l'emprunter ou le retourner).
  • La méthode rechercherParTitre peut utiliser un Stream pour simplifier la recherche.
  • Encapsulez les données dans les classes Livre et Bibliotheque pour respecter les principes d'encapsulation.

5. Concepts abordés

  • Conception de classes orientées objet.
  • Utilisation des collections pour gérer des données dynamiques.
  • Interactions utilisateur via un menu en boucle.

6. Temps estimé

Un développeur expert mettrait environ 45 minutes à 1 heure pour résoudre cet exercice.
