Exercice 11 : Gestionnaire de Notes

1. Objectif

Créer une application simple pour gérer les notes d'étudiants. Vous utiliserez les Collections pour stocker les données et les Streams pour effectuer des calculs et manipuler les données de manière fonctionnelle.

2. Énoncé

Écrivez un programme en Java qui :

  1. Demande à l'utilisateur d'entrer les noms des étudiants et leurs notes (sur 20).
  2. Stocke les données dans une Map où :
    • La clé est le nom de l'étudiant (String).
    • La valeur est la note de l'étudiant (Double).
  3. Affiche les statistiques suivantes :
    • La moyenne des notes.
    • La note maximale et l'étudiant correspondant.
    • La note minimale et l'étudiant correspondant.
  4. Affiche la liste des étudiants ayant une note supérieure ou égale à la moyenne.

3. Exemple attendu

Entrez le nom de l'étudiant (ou "fin" pour terminer) : Alice
Entrez la note de Alice : 15
Entrez le nom de l'étudiant (ou "fin" pour terminer) : Bob
Entrez la note de Bob : 12
Entrez le nom de l'étudiant (ou "fin" pour terminer) : Charlie
Entrez la note de Charlie : 18
Entrez le nom de l'étudiant (ou "fin" pour terminer) : fin

Moyenne des notes : 15.0
Note maximale : 18 (Charlie)
Note minimale : 12 (Bob)
Étudiants ayant une note supérieure ou égale à la moyenne :
- Alice (15)
- Charlie (18)

4. Conseils techniques

  • Utilisez une boucle pour collecter les noms et notes des étudiants. Arrêtez-vous lorsque l'utilisateur entre fin.
  • Utilisez les Streams pour effectuer des calculs comme la moyenne et filtrer les étudiants ayant une note >= moyenne.
  • Pour la note maximale/minimale, utilisez les méthodes de Collections ou des Streams.

5. Concepts abordés

  • Utilisation de la classe HashMap pour stocker des données clé-valeur.
  • Manipulation des Streams pour effectuer des calculs et filtrer les données.
  • Gestion des entrées utilisateur avec une boucle.

6. Temps estimé

Un développeur expert mettrait environ 30 à 45 minutes pour résoudre cet exercice.
