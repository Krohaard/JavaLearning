Flux d'Entrée/Sortie (I/O) en Java

Introduction aux Flux I/O

Les flux I/O en Java permettent de lire et d'écrire des données à partir de diverses sources. Ils sont utilisés pour interagir avec des fichiers, des réseaux, et des périphériques.

Pour plus d'informations, consultez la documentation officielle.

Types de Flux

  • Flux de Byte : Utilisés pour lire et écrire des données binaires (par exemple, InputStream, OutputStream).
  • Flux de Caractères : Utilisés pour lire et écrire des données textuelles (par exemple, Reader, Writer).

Exemples

Exemple 1 : Lecture d'un fichier texte avec BufferedReader.

import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;

public class LectureFichier {
    public static void main(String[] args) {
        try (BufferedReader br = new BufferedReader(new FileReader("fichier.txt"))) {
            String ligne;
            while ((ligne = br.readLine()) != null) {
                System.out.println(ligne);
            }
        } catch (IOException e) {
            System.out.println("Erreur de lecture du fichier : " + e.getMessage());
        }
    }
}

Exemple 2 : Écriture dans un fichier texte avec BufferedWriter.

import java.io.BufferedWriter;
import java.io.FileWriter;
import java.io.IOException;

public class EcritureFichier {
    public static void main(String[] args) {
        try (BufferedWriter bw = new BufferedWriter(new FileWriter("fichier.txt"))) {
            bw.write("Bonjour, ceci est un test d'écriture dans un fichier.");
        } catch (IOException e) {
            System.out.println("Erreur d'écriture dans le fichier : " + e.getMessage());
        }
    }
}

Fonctions Utiles

Méthodes de Flux :

  • read() : Lit un caractère ou un byte.
  • write() : Écrit un caractère ou un byte.
  • close() : Ferme le flux.
