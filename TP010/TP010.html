Gestion des Exceptions en Java

Introduction aux Exceptions

Les exceptions en Java sont des événements qui interrompent le flux normal d'exécution d'un programme. Elles permettent de gérer les erreurs et les situations inhabituelles de manière contrôlée.

Pour plus d'informations, consultez la documentation officielle.

Types d'Exceptions

  • Exceptions Vérifiées (Checked Exceptions) : Doivent être soit capturées, soit déclarées dans une clause throws (par exemple, IOException).
  • Exceptions Non Vérifiées (Unchecked Exceptions) : Héritent de RuntimeException et ne sont pas obligatoirement capturées ou déclarées (par exemple, NullPointerException).

Blocs Try-Catch

Exemple 1 : Utilisation d'un bloc try-catch pour gérer une exception.

public class ExempleException {
    public static void main(String[] args) {
        try {
            int resultat = 10 / 0; // Cela lèvera une ArithmeticException
        } catch (ArithmeticException e) {
            System.out.println("Erreur : Division par zéro.");
        }
    }
}

Bloc Finally

Exemple 2 : Utilisation d'un bloc finally pour exécuter du code quoi qu'il arrive.

public class ExempleFinally {
    public static void main(String[] args) {
        try {
            int resultat = 10 / 0;
        } catch (ArithmeticException e) {
            System.out.println("Erreur : Division par zéro.");
        } finally {
            System.out.println("Ce bloc s'exécute toujours.");
        }
    }
}

Fonctions Utiles

Méthodes de Gestion des Exceptions :

  • printStackTrace() : Affiche la trace de la pile des appels de méthodes.
  • getMessage() : Retourne le message d'erreur de l'exception.
