Exercice 10 : Collections en Java

1. Cours explicatif

Objectif : Comprendre les collections Java, comme les listes, les ensembles et les maps.

Concepts abordés

  • List : Une collection ordonnée qui permet les doublons (exemple : ArrayList).
  • Set : Une collection non ordonnée qui ne permet pas les doublons (exemple : HashSet).
  • Map : Une collection de paires clé-valeur (exemple : HashMap).

Exemple simple

Voici un exemple pour illustrer l'utilisation de trois types de collections :

import java.util.*;

public class ExempleCollections {
    public static void main(String[] args) {
        // List : Accepte les doublons
        List<String> liste = new ArrayList<>();
        liste.add("Java");
        liste.add("Python");
        liste.add("Java");
        System.out.println("Liste : " + liste);

        // Set : Pas de doublons
        Set<String> ensemble = new HashSet<>();
        ensemble.add("Java");
        ensemble.add("Python");
        ensemble.add("Java");
        System.out.println("Ensemble : " + ensemble);

        // Map : Paires clé-valeur
        Map<String, Integer> map = new HashMap<>();
        map.put("Java", 1995);
        map.put("Python", 1991);
        System.out.println("Map : " + map);
    }
}

2. Énoncé

Écris un programme qui :

  1. Crée une ArrayList pour stocker des nombres entiers.
  2. Ajoute 10 nombres aléatoires compris entre 1 et 100 dans cette liste.
  3. Affiche les nombres de la liste.
  4. Affiche :
    • Le nombre le plus grand.
    • Le nombre le plus petit.
    • La somme de tous les nombres.
    • La moyenne des nombres.
  5. Supprime les nombres pairs de la liste et affiche la liste mise à jour.

3. Exemple attendu

Liste originale : [45, 12, 78, 33, 56, 89, 24, 10, 67, 90]
Plus grand : 90
Plus petit : 10
Somme : 504
Moyenne : 50.4
Liste après suppression des nombres pairs : [45, 33, 89, 67]

4. Conseils techniques

  • Utilise la classe Random pour générer des nombres aléatoires.
  • Utilise les méthodes de Collections pour trouver le maximum et le minimum.
  • Utilise un Iterator pour supprimer les nombres pairs de la liste.
