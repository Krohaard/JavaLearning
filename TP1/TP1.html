Exercice TP1: Collecte et affichage des informations utilisateur

Objectif : Manipuler les variables et interagir avec l'utilisateur en Java.
  • Écris un programme qui :
    • Demande à l'utilisateur :
      • Son nom (chaîne de caractères).
      • Son âge (entier).
      • Son salaire (nombre décimal).
    • Affiche ces informations dans une phrase formatée.
      Bonjour [Nom], vous avez [Âge] ans et vous gagnez [Salaire] €.
  • Les étapes dans le programme :
    • Créer un scanner pour lire les entrées utilisateur.
    • Stocker les informations dans des variables appropriées.
    • Afficher une phrase dans ce format :
  • Exemple d'exécution attendu :
    Entrez votre nom : Alice
    Entrez votre âge : 30
    Entrez votre salaire : 3500.50
    Bonjour Alice, vous avez 30 ans et vous gagnez 3500.50 €.

Conseils techniques

  • Utilise Scanner pour lire les entrées utilisateur :
    Scanner scanner = new Scanner(System.in);
  • Ferme toujours ton scanner après utilisation :
    scanner.close();
  • Pour formater les nombres décimaux, tu peux utiliser System.out.printf :
    System.out.printf("Bonjour %s, vous avez %d ans et vous gagnez %.2f €.\n", nom, age, salaire);
