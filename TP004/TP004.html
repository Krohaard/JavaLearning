Structures de Contrôle en Java

Conditions

Les structures conditionnelles permettent d'exécuter différentes parties du code en fonction de certaines conditions.

  • if : Exécute un bloc de code si une condition est vraie.
  • else : Exécute un bloc de code si la condition précédente est fausse.
  • else if : Permet de vérifier plusieurs conditions.
  • switch : Permet de sélectionner une valeur parmi plusieurs cas.

Pour plus d'informations, consultez la documentation officielle.

Boucles

Les boucles permettent de répéter un bloc de code plusieurs fois.

  • for : Boucle qui s'exécute un nombre défini de fois.
  • while : Boucle qui s'exécute tant qu'une condition est vraie.
  • do-while : Boucle qui s'exécute au moins une fois, puis continue tant qu'une condition est vraie.

Exemples

Exemple 1 : Structure if-else.

int age = 20;
if (age >= 18) {
    System.out.println("Adulte");
} else {
    System.out.println("Mineur");
}

Exemple 2 : Boucle for.

for (int i = 0; i < 5; i++) {
    System.out.println("Itération : " + i);
}

Exemple 3 : Boucle while.

int i = 0;
while (i < 5) {
    System.out.println("Itération : " + i);
    i++;
}

Fonctions Utiles

Mathématiques :

  • Math.random() : Génère un nombre aléatoire entre 0.0 et 1.0.
