Exercice 3 : Statistiques sur un tableau

Objectif : Manipuler les tableaux et les boucles en Java.

Énoncé

  1. Écris un programme qui :
    • Demande à l'utilisateur combien de nombres il souhaite saisir.
    • Lit ces nombres et les stocke dans un tableau.
    • Calcule et affiche :
      • La somme des nombres.
      • La moyenne des nombres.
      • Le plus grand nombre.
      • Le plus petit nombre.
  2. Contraintes :
    • Gérer les cas où l'utilisateur entre un tableau vide (affiche un message et termine le programme).
    • Utiliser des boucles pour parcourir le tableau.

Exemple attendu

Combien de nombres souhaitez-vous saisir ? 5
Entrez le nombre 1 : 10
Entrez le nombre 2 : 25
Entrez le nombre 3 : 7
Entrez le nombre 4 : 42
Entrez le nombre 5 : 3

Somme : 87
Moyenne : 17.4
Plus grand nombre : 42
Plus petit nombre : 3

Conseils techniques

  • Crée un tableau avec une taille dynamique : 
    int[] tableau = new int[taille];
  • Utilise une boucle for pour remplir le tableau et pour effectuer les calculs.
  • Exemple pour calculer la somme : 
    int somme = 0;
for (int i = 0; i < tableau.length; i++) {
    somme += tableau[i];
}
