Cours : Lecture et écriture de fichiers en Java

1. Concepts fondamentaux

En Java, il existe plusieurs classes pour lire et écrire des fichiers. Voici les plus courantes :

  • File : Représente un fichier ou un répertoire. Elle permet de vérifier si le fichier existe, d’obtenir sa taille, etc.
  • FileReader et FileWriter : Classes simples pour lire et écrire des fichiers texte.
  • BufferedReader et BufferedWriter : Fournissent une lecture et une écriture plus efficaces grâce au buffering.
  • Files : Une classe utilitaire introduite avec Java 7, qui permet de travailler facilement avec les fichiers.

2. Écriture dans un fichier

Voici trois façons courantes d’écrire dans un fichier :

a. Avec FileWriter

import java.io.FileWriter;
import java.io.IOException;

public class ExempleFileWriter {
    public static void main(String[] args) {
        try (FileWriter writer = new FileWriter("exemple.txt")) {
            writer.write("Bonjour, fichier !");
        } catch (IOException e) {
            System.out.println("Erreur : " + e.getMessage());
        }
    }
}

b. Avec BufferedWriter

import java.io.BufferedWriter;
import java.io.FileWriter;
import java.io.IOException;

public class ExempleBufferedWriter {
    public static void main(String[] args) {
        try (BufferedWriter writer = new BufferedWriter(new FileWriter("exemple.txt"))) {
            writer.write("Ligne 1");
            writer.newLine(); // Ajout d'un saut de ligne
            writer.write("Ligne 2");
        } catch (IOException e) {
            System.out.println("Erreur : " + e.getMessage());
        }
    }
}

c. Avec Files.write()

import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.StandardOpenOption;
import java.util.List;

public class ExempleFilesWrite {
    public static void main(String[] args) {
        List<String> lignes = List.of("Ligne 1", "Ligne 2", "Ligne 3");
        try {
            Files.write(Path.of("exemple.txt"), lignes, StandardOpenOption.CREATE);
        } catch (IOException e) {
            System.out.println("Erreur : " + e.getMessage());
        }
    }
}

3. Lecture d’un fichier

Voici trois façons courantes de lire un fichier :

a. Avec FileReader et BufferedReader

import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;

public class ExempleBufferedReader {
    public static void main(String[] args) {
        try (BufferedReader reader = new BufferedReader(new FileReader("exemple.txt"))) {
            String ligne;
            while ((ligne = reader.readLine()) != null) {
                System.out.println(ligne);
            }
        } catch (IOException e) {
            System.out.println("Erreur : " + e.getMessage());
        }
    }
}

b. Avec Files.readAllLines()

import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.List;

public class ExempleFilesReadAllLines {
    public static void main(String[] args) {
        try {
            List<String> lignes = Files.readAllLines(Path.of("exemple.txt"));
            for (String ligne : lignes) {
                System.out.println(ligne);
            }
        } catch (IOException e) {
            System.out.println("Erreur : " + e.getMessage());
        }
    }
}

c. Avec Scanner

import java.io.File;
import java.io.IOException;
import java.util.Scanner;

public class ExempleScanner {
    public static void main(String[] args) {
        try (Scanner scanner = new Scanner(new File("exemple.txt"))) {
            while (scanner.hasNextLine()) {
                System.out.println(scanner.nextLine());
            }
        } catch (IOException e) {
            System.out.println("Erreur : " + e.getMessage());
        }
    }
}

4. Conseils

  • Utilise toujours un bloc try-with-resources pour fermer automatiquement les ressources.
  • Préférer les classes modernes comme Files pour leur simplicité.
  • Gère les exceptions pour éviter les plantages inattendus.
