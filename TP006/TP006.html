Héritage en Java

Concept d'Héritage

L'héritage est un mécanisme qui permet à une classe (appelée sous-classe ou classe dérivée) d'hériter des attributs et des méthodes d'une autre classe (appelée super-classe ou classe de base).

Pour plus d'informations, consultez la documentation officielle.

Création d'une Sous-Classe

Exemple 1 : Définition d'une classe de base et d'une sous-classe.

class Animal {
    // Attribut
    String nom;

    // Constructeur
    public Animal(String nom) {
        this.nom = nom;
    }

    // Méthode
    public void faireDuBruit() {
        System.out.println("L'animal fait du bruit.");
    }
}

class Chien extends Animal {
    // Constructeur
    public Chien(String nom) {
        super(nom);
    }

    // Surcharge de la méthode faireDuBruit
    @Override
    public void faireDuBruit() {
        System.out.println("Le chien aboie.");
    }
}

Utilisation de l'Héritage

Exemple 2 : Utilisation de la sous-classe.

public class Main {
    public static void main(String[] args) {
        // Création d'un objet Chien
        Chien monChien = new Chien("Rex");
        // Appel de la méthode surchargée
        monChien.faireDuBruit();
    }
}

Fonctions Utiles

Méthodes d'Héritage :

  • super() : Appelle le constructeur de la super-classe.
  • super.methode() : Appelle une méthode de la super-classe.

Exercices
