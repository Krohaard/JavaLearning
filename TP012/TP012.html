Threads en Java

Introduction aux Threads

Les threads en Java permettent d'exécuter plusieurs tâches en parallèle. Ils sont utilisés pour améliorer les performances des applications en tirant parti des processeurs multi-cœurs.

Pour plus d'informations, consultez la documentation officielle.

Création d'un Thread

Exemple 1 : Création d'un thread en étendant la classe Thread.

class MonThread extends Thread {
    public void run() {
        System.out.println("Thread en cours d'exécution.");
    }
}

public class ExempleThread {
    public static void main(String[] args) {
        MonThread thread = new MonThread();
        thread.start(); // Démarre le thread
    }
}

Exemple 2 : Création d'un thread en implémentant l'interface Runnable.

class MonRunnable implements Runnable {
    public void run() {
        System.out.println("Runnable en cours d'exécution.");
    }
}

public class ExempleRunnable {
    public static void main(String[] args) {
        Thread thread = new Thread(new MonRunnable());
        thread.start(); // Démarre le thread
    }
}

Synchronisation des Threads

Exemple 3 : Utilisation de synchronized pour éviter les conflits d'accès.

class Compteur {
    private int valeur = 0;

    public synchronized void incrementer() {
        valeur++;
    }

    public int getValeur() {
        return valeur;
    }
}

public class ExempleSynchronisation {
    public static void main(String[] args) throws InterruptedException {
        Compteur compteur = new Compteur();

        Runnable tache = () -> {
            for (int i = 0; i < 1000; i++) {
                compteur.incrementer();
            }
        };

        Thread thread1 = new Thread(tache);
        Thread thread2 = new Thread(tache);

        thread1.start();
        thread2.start();

        thread1.join();
        thread2.join();

        System.out.println("Valeur finale : " + compteur.getValeur());
    }
}

Fonctions Utiles

Méthodes de Thread :

  • start() : Démarre l'exécution du thread.
  • run() : Méthode contenant le code à exécuter par le thread.
  • join() : Attend que le thread se termine.
