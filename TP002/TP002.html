Types de Données et Variables en Java

Types de Données

En Java, les types de données définissent le type de valeur qu'une variable peut contenir. Il existe deux catégories principales : les types primitifs et les types référencés.

Types Primitifs :

  • byte : 8 bits, valeurs de -128 à 127.
  • short : 16 bits, valeurs de -32,768 à 32,767.
  • int : 32 bits, valeurs de -2^31 à 2^31-1.
  • long : 64 bits, valeurs de -2^63 à 2^63-1.
  • float : 32 bits, nombres à virgule flottante.
  • double : 64 bits, nombres à virgule flottante de plus grande précision.
  • boolean : valeurs true ou false.
  • char : 16 bits, caractères Unicode.

Pour plus d'informations, consultez la documentation officielle.

Variables

Une variable est un conteneur pour stocker des données. En Java, tu dois déclarer une variable avec un type avant de pouvoir l'utiliser.

Exemple 1 : Déclaration et initialisation d'une variable.

int age = 25;

Exemple 2 : Utilisation de différents types de données.

double price = 19.99;
char grade = 'A';
boolean isStudent = true;

Exemple 3 : Modification de la valeur d'une variable.

int score = 100;
score = 150;

Fonctions Utiles

Conversion de Types :

  • Integer.parseInt(String s) : Convertit une chaîne en un entier.
  • Double.parseDouble(String s) : Convertit une chaîne en un double.
  • String.valueOf(int i) : Convertit un entier en une chaîne.

Affichage :

  • System.out.println(variable) : Affiche la valeur de la variable dans la console.
