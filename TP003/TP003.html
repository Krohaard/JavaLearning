Opérateurs en Java

Types d'Opérateurs

Les opérateurs sont des symboles qui effectuent des opérations sur des variables et des valeurs. Java supporte plusieurs types d'opérateurs :

  • Arithmétiques : +, -, *, /, %
  • Relationnels : ==, !=, >, <, >=, <=
  • Logiques : &&, ||, !
  • D'affectation : =, +=, -=, *=, /=
  • D'incrémentation/décrémentation : ++, --

Pour plus d'informations, consultez la documentation officielle.

Utilisation des Opérateurs

Exemple 1 : Opérateurs arithmétiques.

int sum = 5 + 3; // sum vaut 8
int difference = 10 - 4; // difference vaut 6
int product = 7 * 2; // product vaut 14
int quotient = 20 / 4; // quotient vaut 5
int remainder = 15 % 4; // remainder vaut 3

Exemple 2 : Opérateurs relationnels.

boolean isEqual = (5 == 3); // isEqual vaut false
boolean isNotEqual = (10 != 5); // isNotEqual vaut true
boolean isGreater = (7 > 2); // isGreater vaut true

Exemple 3 : Opérateurs logiques.

boolean andResult = (true && false); // andResult vaut false
boolean orResult = (true || false); // orResult vaut true
boolean notResult = !true; // notResult vaut false

Fonctions Utiles

Mathématiques :

  • Math.abs(int a) : Retourne la valeur absolue d'un entier.
  • Math.max(int a, int b) : Retourne le plus grand des deux entiers.
  • Math.min(int a, int b) : Retourne le plus petit des deux entiers.
