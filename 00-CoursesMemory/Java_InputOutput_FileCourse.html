Cours sur l'écriture et la lecture de fichiers en Java

Introduction

Dans ce cours, nous allons apprendre à lire et écrire des fichiers en Java. Nous aborderons les différentes classes et méthodes disponibles pour manipuler des fichiers texte et binaires.

Lecture de fichiers

Utilisation de FileReader et BufferedReader


import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;

public class LectureFichier {
    public static void main(String[] args) {
        try (BufferedReader br = new BufferedReader(new FileReader("fichier.txt"))) {
            String ligne;
            while ((ligne = br.readLine()) != null) {
                System.out.println(ligne);
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}

Utilisation de Scanner


import java.io.File;
import java.io.FileNotFoundException;
import java.util.Scanner;

public class LectureFichierScanner {
    public static void main(String[] args) {
        try (Scanner scanner = new Scanner(new File("fichier.txt"))) {
            while (scanner.hasNextLine()) {
                String ligne = scanner.nextLine();
                System.out.println(ligne);
            }
        } catch (FileNotFoundException e) {
            e.printStackTrace();
        }
    }
}

Gestion des exceptions

Il est important de gérer les exceptions lors de la lecture de fichiers pour éviter des erreurs inattendues. Utilisez des blocs try-catch pour capturer les exceptions.

Écriture de fichiers

Utilisation de FileWriter et BufferedWriter


import java.io.BufferedWriter;
import java.io.FileWriter;
import java.io.IOException;

public class EcritureFichier {
    public static void main(String[] args) {
        try (BufferedWriter bw = new BufferedWriter(new FileWriter("fichier.txt"))) {
            bw.write("Bonjour, monde !");
            bw.newLine();
            bw.write("Ceci est un exemple d'écriture de fichier.");
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}

Utilisation de PrintWriter


import java.io.FileNotFoundException;
import java.io.PrintWriter;

public class EcritureFichierPrintWriter {
    public static void main(String[] args) {
        try (PrintWriter pw = new PrintWriter("fichier.txt")) {
            pw.println("Bonjour, monde !");
            pw.println("Ceci est un exemple d'écriture de fichier avec PrintWriter.");
        } catch (FileNotFoundException e) {
            e.printStackTrace();
        }
    }
}

Gestion des exceptions

Comme pour la lecture, l'écriture de fichiers peut générer des exceptions. Utilisez des blocs try-catch pour les gérer.

Manipulation de fichiers binaires

Utilisation de FileInputStream et FileOutputStream


import java.io.FileInputStream;
import java.io.FileOutputStream;
import java.io.IOException;

public class FichierBinaire {
    public static void main(String[] args) {
        try (FileInputStream fis = new FileInputStream("entree.bin");
             FileOutputStream fos = new FileOutputStream("sortie.bin")) {
            int octet;
            while ((octet = fis.read()) != -1) {
                fos.write(octet);
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}

Utilisation de DataInputStream et DataOutputStream


import java.io.DataInputStream;
import java.io.DataOutputStream;
import java.io.FileInputStream;
import java.io.FileOutputStream;
import java.io.IOException;

public class FichierBinaireData {
    public static void main(String[] args) {
        try (DataInputStream dis = new DataInputStream(new FileInputStream("entree.bin"));
             DataOutputStream dos = new DataOutputStream(new FileOutputStream("sortie.bin"))) {
            int donnee;
            while ((donnee = dis.readInt()) != -1) {
                dos.writeInt(donnee);
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
