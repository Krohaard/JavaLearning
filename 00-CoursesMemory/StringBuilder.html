Utilisation de StringBuilder en Java

Chapitre 1 : Introduction à StringBuilder

Théorie : StringBuilder est une classe en Java utilisée pour créer et manipuler des chaînes de caractères modifiables. Contrairement à la classe String, qui est immuable, StringBuilder permet de modifier la chaîne sans créer de nouveaux objets. Cela rend StringBuilder plus efficace pour les opérations de concaténation et de modification fréquentes.

Exemple 1 : Création et utilisation de base

public class ExempleStringBuilder {
    public static void main(String[] args) {
        StringBuilder sb = new StringBuilder();
        sb.append("Bonjour");
        sb.append(" ");
        sb.append("tout le monde !");
        System.out.println(sb.toString()); // Affiche : Bonjour tout le monde !
    }
}

Exemple 2 : Modification de la chaîne

public class ModificationStringBuilder {
    public static void main(String[] args) {
        StringBuilder sb = new StringBuilder("Bonjour");
        sb.insert(7, " à tous"); // Insère " à tous" à l'index 7
        sb.replace(0, 7, "Salut"); // Remplace "Bonjour" par "Salut"
        sb.delete(5, 10); // Supprime les caractères de l'index 5 à 9
        System.out.println(sb.toString()); // Affiche : Salut à tous
    }
}

Exemple 3 : Inversion de la chaîne

public class InversionStringBuilder {
    public static void main(String[] args) {
        StringBuilder sb = new StringBuilder("Bonjour");
        sb.reverse();
        System.out.println(sb.toString()); // Affiche : ruojnoB
    }
}

Chapitre 2 : Performances et Bonnes Pratiques

Théorie : StringBuilder est particulièrement utile dans les boucles ou lorsque plusieurs modifications sont nécessaires sur une chaîne. Il est plus performant que l'utilisation de String avec l'opérateur + pour la concaténation, car il évite la création de nombreux objets intermédiaires.

Exemple 1 : Utilisation dans une boucle

public class BoucleStringBuilder {
    public static void main(String[] args) {
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < 10; i++) {
            sb.append("Nombre : ").append(i).append("\n");
        }
        System.out.println(sb.toString());
    }
}

Exemple 2 : Comparaison avec String

public class ComparaisonString {
    public static void main(String[] args) {
        String str = "";
        for (int i = 0; i < 10; i++) {
            str += "Nombre : " + i + "\n"; // Moins performant
        }
        System.out.println(str);
    }
}

Exemple 3 : Capacité et gestion de la mémoire

public class CapaciteStringBuilder {
    public static void main(String[] args) {
        StringBuilder sb = new StringBuilder(50); // Capacité initiale de 50
        sb.ensureCapacity(100); // Augmente la capacité à 100 si nécessaire
        System.out.println("Capacité : " + sb.capacity());
    }
}
