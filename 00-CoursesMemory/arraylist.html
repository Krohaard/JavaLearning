Les Listes en Java

Introduction

Une List en Java est une collection ordonnée qui permet des éléments dupliqués. Elle fait partie du framework java.util et étend l'interface Collection.

Caractéristiques

  • Accès aux éléments par index
  • Permet les doublons
  • Implémentations courantes : ArrayList, LinkedList

Exemple de base avec List

import java.util.ArrayList;
import java.util.List;

public class ExempleList {
    public static void main(String[] args) {
        List<String> fruits = new ArrayList<>();
        fruits.add("Pomme");
        fruits.add("Banane");
        fruits.add(1, "Orange"); // Ajout à un index spécifique
        
        System.out.println("Liste de fruits : " + fruits);
        System.out.println("Élément à l'index 2 : " + fruits.get(2));
    }
}

Résultat :

Liste de fruits : [Pomme, Orange, Banane]
Élément à l'index 2 : Banane

ArrayList

Introduction

La classe ArrayList est une implémentation de tableau redimensionnable de l'interface List.

Caractéristiques

  • Accès rapide aux éléments par index (O(1))
  • Insertion/suppression lente au milieu (O(n))
  • Non synchronisé (pas thread-safe)

Exemple avancé avec ArrayList

import java.util.ArrayList;
import java.util.Collections;

public class ExempleArrayList {
    public static void main(String[] args) {
        ArrayList<Integer> nombres = new ArrayList<>();
        nombres.add(5);
        nombres.add(2);
        nombres.add(8);
        
        Collections.sort(nombres); // Tri de la liste
        nombres.removeIf(n -> n % 2 == 0); // Suppression des nombres pairs
        
        System.out.println("Liste filtrée : " + nombres);
    }
}

Résultat :

Liste filtrée : [5]

Les Streams en Java

Introduction

Les Stream (introduits dans Java 8) permettent des opérations de traitement de données de manière déclarative.

Caractéristiques

  • Opérations en pipeline
  • Ne modifie pas la source de données
  • Peut être parallélisé

Exemple de base avec Stream

import java.util.List;
import java.util.stream.Collectors;

public class ExempleStream {
    public static void main(String[] args) {
        List<String> mots = List.of("Java", "Stream", "API", "Collections");
        
        List<String> resultat = mots.stream()
            .filter(mot -> mot.length() > 4)
            .map(String::toUpperCase)
            .collect(Collectors.toList());
            
        System.out.println("Résultat : " + resultat);
    }
}

Résultat :

Résultat : [STREAM, COLLECTIONS]

Exemple complexe avec Stream

import java.util.Arrays;
import java.util.IntSummaryStatistics;
import java.util.List;

public class StreamComplexe {
    public static void main(String[] args) {
        List<Integer> nombres = Arrays.asList(1, 2, 3, 4, 5, 6, 7, 8, 9);
        
        IntSummaryStatistics stats = nombres.stream()
            .filter(n -> n % 2 == 0)
            .mapToInt(n -> n * 2)
            .summaryStatistics();
            
        System.out.println("Moyenne : " + stats.getAverage());
        System.out.println("Max : " + stats.getMax());
    }
}

Résultat :

Moyenne : 10.0
Max : 16

Conclusion

Ces trois concepts sont fondamentaux en Java :

  • List : Interface de base pour les collections ordonnées
  • ArrayList : Implémentation optimisée pour l'accès aléatoire
  • Stream : API moderne pour le traitement déclaratif des données
