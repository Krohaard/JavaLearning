Cours : Iterator en Java

1. Qu'est-ce qu'un Iterator ?

En Java, un Iterator est une interface qui permet de parcourir une collection (ex. : ArrayList, HashSet) de manière séquentielle sans exposer sa structure interne.

Caractéristiques principales :

  • Fournit des méthodes pour parcourir les éléments d'une collection.
  • Permet de supprimer des éléments en toute sécurité lors du parcours.
  • Évite les problèmes de modification concurrente (ConcurrentModificationException).

2. Méthodes de l'interface Iterator

  • hasNext() :

    Retourne true s'il y a un autre élément à parcourir.

    Iterator<String> it = liste.iterator();
while (it.hasNext()) {
    System.out.println(it.next());
}
  • next() :

    Retourne l'élément suivant de la collection.

    Attention : Si aucun élément n'est disponible, l'appel lève une NoSuchElementException.

  • remove() :

    Supprime l'élément courant de la collection. Cette méthode ne peut être appelée qu'une seule fois après chaque next().

    Iterator<Integer> it = liste.iterator();
while (it.hasNext()) {
    int val = it.next();
    if (val % 2 == 0) { // Supprime les nombres pairs
        it.remove();
    }
}

3. Exemple simple avec Iterator

import java.util.ArrayList;
import java.util.Iterator;

public class ExempleIterator {
    public static void main(String[] args) {
        ArrayList<String> noms = new ArrayList<>();
        noms.add("Alice");
        noms.add("Bob");
        noms.add("Charlie");

        Iterator<String> it = noms.iterator();
        System.out.println("Parcours de la liste :");
        while (it.hasNext()) {
            System.out.println(it.next());
        }
    }
}

4. Exemple avec suppression sécurisée

import java.util.ArrayList;
import java.util.Iterator;

public class ExempleSuppression {
    public static void main(String[] args) {
        ArrayList<Integer> nombres = new ArrayList<>();
        nombres.add(10);
        nombres.add(15);
        nombres.add(20);

        Iterator<Integer> it = nombres.iterator();
        while (it.hasNext()) {
            if (it.next() % 2 == 0) { // Supprime les nombres pairs
                it.remove();
            }
        }

        System.out.println("Liste après suppression : " + nombres);
    }
}

5. Différences entre Iterator et for-each

Caractéristique Iterator For-each
Suppression d'éléments Possible avec remove(). Non sécurisé, lève une exception si utilisé directement.
Simplicité Plus détaillé mais plus verbeux. Plus compact et lisible.
Utilisation universelle Compatible avec toutes les collections. Uniquement les collections qui implémentent Iterable.
