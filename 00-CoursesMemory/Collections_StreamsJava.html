Différence entre Streams et Collections en Java

1. Introduction

Les Collections et les Streams sont deux concepts clés de la programmation en Java, mais ils servent à des fins différentes :

  • Collections : Structures de données qui stockent des objets en mémoire.
  • Streams : Un flux d'éléments qui permet de traiter les données de manière déclarative et fonctionnelle.

2. Principales différences

Caractéristique Collections Streams
Nature Stockent des données en mémoire. Représentent un flux d'éléments traités séquentiellement ou parallèlement.
État Mutable : Les éléments peuvent être ajoutés, modifiés ou supprimés. Immuable : Une fois le flux traité, il ne peut plus être réutilisé.
Itération Itération externe avec des boucles (ex. : for-each). Itération interne avec des méthodes comme forEach.
Traitement Principalement impératif. Déclaratif et fonctionnel.
Parallélisme Non pris en charge directement. Prise en charge native avec parallelStream().

3. Exemple pratique

3.1 Avec une Collection

import java.util.ArrayList;

public class ExempleCollection {
    public static void main(String[] args) {
        ArrayList<Integer> nombres = new ArrayList<>();
        nombres.add(10);
        nombres.add(20);
        nombres.add(30);

        int somme = 0;
        for (int nombre : nombres) {
            somme += nombre;
        }
        System.out.println("Somme : " + somme);
    }
}

3.2 Avec un Stream

import java.util.ArrayList;

public class ExempleStream {
    public static void main(String[] args) {
        ArrayList<Integer> nombres = new ArrayList<>();
        nombres.add(10);
        nombres.add(20);
        nombres.add(30);

        int somme = nombres.stream()
                           .mapToInt(Integer::intValue)
                           .sum();

        System.out.println("Somme : " + somme);
    }
}

4. Quand utiliser un Stream ou une Collection ?

  • Collections : Utilisez-les pour stocker et manipuler des données sur plusieurs étapes (ajout, suppression, tri, etc.).
  • Streams : Utilisez-les pour effectuer un traitement en une étape (filtrage, transformation, réduction).
