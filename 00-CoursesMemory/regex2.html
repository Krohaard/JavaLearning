Cours sur les Regex en Java

Introduction aux Regex

Les expressions régulières (regex) sont des séquences de caractères formant un motif de recherche. Elles sont utilisées pour la recherche, le remplacement et la validation de chaînes de caractères.

Syntaxe de Base

Voici quelques éléments de base de la syntaxe des regex :

  • . : Correspond à n'importe quel caractère sauf un saut de ligne.
  • ^ : Correspond au début d'une ligne.
  • $ : Correspond à la fin d'une ligne.
  • * : Correspond à 0 ou plusieurs occurrences du caractère précédent.
  • + : Correspond à 1 ou plusieurs occurrences du caractère précédent.
  • ? : Correspond à 0 ou 1 occurrence du caractère précédent.
  • [] : Correspond à un caractère parmi ceux entre crochets.
  • | : Correspond à l'un ou l'autre des motifs séparés par le pipe.
  • \ : Échappe un caractère spécial.

Chiffres et Caractères Spéciaux

Les regex permettent également de travailler avec des chiffres et des caractères spéciaux :

  • \d : Correspond à n'importe quel chiffre (équivalent à [0-9]).
  • \D : Correspond à tout caractère qui n'est pas un chiffre.
  • \w : Correspond à n'importe quel caractère alphanumérique ou souligné (équivalent à [a-zA-Z0-9_]).
  • \W : Correspond à tout caractère qui n'est pas alphanumérique ou souligné.
  • \s : Correspond à n'importe quel caractère d'espacement (espace, tabulation, etc.).
  • \S : Correspond à tout caractère qui n'est pas un espace.
  • \b : Correspond à une limite de mot.
  • \B : Correspond à une position qui n'est pas une limite de mot.

Utilisation des Regex en Java

En Java, les regex sont utilisées via les classes Pattern et Matcher du package java.util.regex.

Exemple 1 : Recherche Simple

import java.util.regex.Pattern;
import java.util.regex.Matcher;

public class RegexExample {
    public static void main(String[] args) {
        String text = "Bonjour, le monde!";
        String regex = "monde";

        Pattern pattern = Pattern.compile(regex);
        Matcher matcher = pattern.matcher(text);

        if (matcher.find()) {
            System.out.println("Motif trouvé!");
        } else {
            System.out.println("Motif non trouvé.");
        }
    }
}

Dans cet exemple, nous recherchons simplement le mot "monde" dans la chaîne "Bonjour, le monde!". La méthode find() de Matcher est utilisée pour vérifier si le motif est présent dans le texte.

Exemple 2 : Utilisation des Groupes

import java.util.regex.Pattern;
import java.util.regex.Matcher;

public class RegexGroupsExample {
    public static void main(String[] args) {
        String text = "Date: 2023-10-01";
        String regex = "Date: (\\d{4})-(\\d{2})-(\\d{2})";

        Pattern pattern = Pattern.compile(regex);
        Matcher matcher = pattern.matcher(text);

        if (matcher.find()) {
            System.out.println("Année: " + matcher.group(1));
            System.out.println("Mois: " + matcher.group(2));
            System.out.println("Jour: " + matcher.group(3));
        }
    }
}

Ici, nous utilisons des groupes pour extraire l'année, le mois et le jour d'une date. Les parenthèses dans le motif (\\d{4})-(\\d{2})-(\\d{2}) définissent trois groupes capturants. La méthode group(int) de Matcher permet de récupérer le texte correspondant à chaque groupe.

Exemple 3 : Remplacement avec Regex

import java.util.regex.Pattern;
import java.util.regex.Matcher;

public class RegexReplaceExample {
    public static void main(String[] args) {
        String text = "Bonjour, le monde!";
        String regex = "monde";
        String replacement = "Java";

        Pattern pattern = Pattern.compile(regex);
        Matcher matcher = pattern.matcher(text);

        String result = matcher.replaceAll(replacement);
        System.out.println(result); // Affiche: Bonjour, le Java!
    }
}

Cet exemple montre comment remplacer toutes les occurrences d'un motif par une autre chaîne. La méthode replaceAll() de Matcher est utilisée pour remplacer "monde" par "Java" dans le texte.

Exemple 4 : Validation d'un Numéro de Téléphone

import java.util.regex.Pattern;
import java.util.regex.Matcher;

public class PhoneValidationExample {
    public static void main(String[] args) {
        String phoneNumber = "123-456-7890";
        String regex = "\\d{3}-\\d{3}-\\d{4}";

        Pattern pattern = Pattern.compile(regex);
        Matcher matcher = pattern.matcher(phoneNumber);

        if (matcher.matches()) {
            System.out.println("Numéro de téléphone valide.");
        } else {
            System.out.println("Numéro de téléphone invalide.");
        }
    }
}

Dans cet exemple, nous validons un numéro de téléphone au format "123-456-7890". Le motif \\d{3}-\\d{3}-\\d{4} vérifie que le numéro est composé de trois groupes de chiffres séparés par des tirets. La méthode matches() de Matcher vérifie si l'ensemble du texte correspond au motif.

Exemple 5 : Extraction d'Emails

import java.util.regex.Pattern;
import java.util.regex.Matcher;

public class EmailExtractorExample {
    public static void main(String[] args) {
        String text = "Contactez-nous à info@example.com ou support@example.org.";
        String regex = "\\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\\.[A-Za-z]{2,}\\b";

        Pattern pattern = Pattern.compile(regex);
        Matcher matcher = pattern.matcher(text);

        while (matcher.find()) {
            System.out.println("Email trouvé: " + matcher.group());
        }
    }
}

Cet exemple montre comment extraire des adresses email d'un texte. Le motif \\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\\.[A-Za-z]{2,}\\b correspond à une structure d'email standard. La méthode find() de Matcher est utilisée pour trouver toutes les occurrences du motif dans le texte.

Conclusion

Les expressions régulières sont un outil puissant pour la manipulation de chaînes de caractères en Java. Elles permettent de définir des motifs de recherche complexes et d'effectuer des opérations de recherche, de remplacement et de validation de manière efficace.
