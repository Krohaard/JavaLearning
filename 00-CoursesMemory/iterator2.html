Cours : La méthode Iterator en Java

1. Qu'est-ce qu'un Iterator ?

Un Iterator est un objet qui permet de parcourir les éléments d'une collection (comme une liste ou un ensemble) de manière séquentielle sans exposer la structure interne de cette collection.

Il est très utile pour parcourir une collection et effectuer des opérations comme la suppression d'éléments en toute sécurité.

2. Pourquoi utiliser un Iterator ?

  • Suppression sécurisée : Lorsqu’on modifie une collection pendant son parcours, un Iterator évite les erreurs comme ConcurrentModificationException.
  • Uniformité : Il fournit un moyen standard de parcourir différentes collections, quelles que soient leurs implémentations.

3. Méthodes principales de l'interface Iterator

Méthode Description
hasNext() Retourne true s'il reste des éléments à parcourir dans la collection.
next() Retourne l'élément suivant de la collection.
remove() Supprime l'élément courant (celui retourné par next()) de la collection.

4. Exemples d'utilisation

4.1 Parcourir une liste

import java.util.ArrayList;
import java.util.Iterator;

public class ExempleIterator {
    public static void main(String[] args) {
        ArrayList<String> noms = new ArrayList<>();
        noms.add("Alice");
        noms.add("Bob");
        noms.add("Charlie");

        Iterator<String> iterator = noms.iterator();

        while (iterator.hasNext()) {
            String nom = iterator.next();
            System.out.println(nom);
        }
    }
}

4.2 Supprimer des éléments pairs d'une liste

import java.util.ArrayList;
import java.util.Iterator;

public class ExempleSuppression {
    public static void main(String[] args) {
        ArrayList<Integer> nombres = new ArrayList<>();
        nombres.add(1);
        nombres.add(2);
        nombres.add(3);
        nombres.add(4);

        Iterator<Integer> iterator = nombres.iterator();

        while (iterator.hasNext()) {
            Integer nombre = iterator.next();
            if (nombre % 2 == 0) { // Supprimer les nombres pairs
                iterator.remove();
            }
        }

        System.out.println("Liste après suppression : " + nombres);
    }
}

4.3 Erreur sans Iterator

Voici un exemple montrant une erreur lorsqu'on utilise une boucle classique pour modifier une collection :

ArrayList<Integer> nombres = new ArrayList<>();
nombres.add(1);
nombres.add(2);
nombres.add(3);

for (Integer nombre : nombres) {
    if (nombre % 2 == 0) {
        nombres.remove(nombre); // Provoque ConcurrentModificationException
    }
}

5. Avantages et limites

5.1 Avantages

  • Permet de parcourir et de modifier des collections de manière sécurisée.
  • Offre une abstraction pour manipuler différentes collections sans connaître leur implémentation.

5.2 Limites

  • Un Iterator est unidirectionnel (parcours dans un seul sens).
  • Il ne permet pas d'ajouter ou de remplacer des éléments directement.

6. Résumé

  • Utilisez Iterator pour parcourir des collections et supprimer des éléments en toute sécurité.
  • Préférez ListIterator si vous avez besoin d’un parcours bidirectionnel.
