Cours : Les exceptions et le try-catch en Java

1. Qu'est-ce qu'une exception ?

En Java, une exception est un événement qui interrompt le déroulement normal d’un programme. Cela se produit lorsqu’une erreur se produit lors de l’exécution, par exemple :

  • Division par zéro.
  • Accès à un fichier inexistant.
  • Index hors limites dans un tableau.

Lorsqu'une exception se produit, Java génère un objet d'exception. Cet objet contient des informations sur l'erreur, telles que son type et son emplacement.

2. Les principales classes d'exceptions

Voici quelques exceptions courantes en Java :

  • ArithmeticException : Erreur arithmétique (exemple : division par zéro).
  • NullPointerException : Tentative d’utiliser un objet qui a la valeur null.
  • ArrayIndexOutOfBoundsException : Tentative d’accéder à un index inexistant dans un tableau.
  • IOException : Erreur d’entrée/sortie (fichiers, flux, etc.).

3. Gestion des exceptions avec try-catch

La gestion des exceptions en Java repose sur le bloc try-catch. Voici comment cela fonctionne :

try {
    // Code susceptible de provoquer une exception
} catch (TypeException e) {
    // Code pour gérer l'exception
}

Exemple : Division par zéro :

public class Exemple {
    public static void main(String[] args) {
        try {
            int resultat = 10 / 0; // Provoque une ArithmeticException
        } catch (ArithmeticException e) {
            System.out.println("Erreur : Division par zéro.");
        }
    }
}

4. Le bloc finally

Le bloc finally est facultatif et s'exécute toujours, qu’une exception soit levée ou non. Il est souvent utilisé pour libérer des ressources (comme fermer un fichier ou une connexion).

try {
    // Code susceptible de provoquer une exception
} catch (Exception e) {
    System.out.println("Erreur : " + e.getMessage());
} finally {
    System.out.println("Bloc finally exécuté.");
}

5. Gérer plusieurs exceptions

Si un code peut lever plusieurs exceptions, tu peux les gérer séparément avec plusieurs blocs catch.

public class Exemple {
    public static void main(String[] args) {
        try {
            int[] tableau = {1, 2, 3};
            System.out.println(tableau[5]); // Provoque une ArrayIndexOutOfBoundsException
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("Erreur : Index hors limites.");
        } catch (Exception e) {
            System.out.println("Erreur générale : " + e.getMessage());
        }
    }
}

6. Propager une exception avec throw

Tu peux utiliser throw pour lever une exception manuellement :

public class Exemple {
    public static void main(String[] args) {
        try {
            verifierAge(15);
        } catch (IllegalArgumentException e) {
            System.out.println("Erreur : " + e.getMessage());
        }
    }

    public static void verifierAge(int age) {
        if (age < 18) {
            throw new IllegalArgumentException("L'âge doit être supérieur ou égal à 18.");
        }
    }
}

7. Exceptions vérifiées et non vérifiées

  • Exceptions vérifiées (checked exceptions) : Elles doivent être déclarées dans le code ou gérées avec un try-catch. Exemple : IOException.
  • Exceptions non vérifiées (unchecked exceptions) : Elles ne nécessitent pas de déclaration. Exemple : NullPointerException.

8. Conseils

  • Utilise des exceptions pour gérer des erreurs exceptionnelles, pas pour contrôler la logique normale.
  • Écris des messages d’erreur clairs pour faciliter le débogage.
  • Ferme toujours les ressources avec finally ou utilise le try-with-resources.
