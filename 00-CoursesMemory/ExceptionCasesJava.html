Cours sur les exceptions en Java

Introduction aux exceptions

Une exception en Java est un événement qui se produit pendant l'exécution d'un programme et qui perturbe le flux normal des instructions. Les exceptions sont utilisées pour gérer les erreurs et les situations inattendues de manière structurée.

La hiérarchie des exceptions en Java est la suivante :

  • Throwable (classe racine)
  • Error (erreurs graves, non gérées)
  • Exception (exceptions vérifiées et non vérifiées)
  • RuntimeException (exceptions non vérifiées)

Types d'exceptions

Exceptions vérifiées (checked exceptions)

Les exceptions vérifiées doivent être gérées explicitement par le programmeur, soit avec un bloc try-catch, soit en les propageant avec throws. Exemple : IOException.


import java.io.FileInputStream;
import java.io.FileNotFoundException;

public class CheckedExceptionExample {
    public static void main(String[] args) {
        try {
            FileInputStream file = new FileInputStream("fichier.txt");
        } catch (FileNotFoundException e) {
            System.out.println("Fichier non trouvé !");
        }
    }
}

Exceptions non vérifiées (unchecked exceptions)

Les exceptions non vérifiées ne nécessitent pas de gestion explicite. Elles sont généralement causées par des erreurs de logique. Exemple : NullPointerException.


public class UncheckedExceptionExample {
    public static void main(String[] args) {
        String str = null;
        try {
            System.out.println(str.length());
        } catch (NullPointerException e) {
            System.out.println("Erreur : la chaîne est null !");
        }
    }
}

Erreurs (errors)

Les erreurs sont des problèmes graves qui ne devraient pas être capturés. Exemple : OutOfMemoryError.

Gestion des exceptions

Bloc try-catch

Le bloc try-catch permet de capturer et de gérer les exceptions.


public class TryCatchExample {
    public static void main(String[] args) {
        try {
            int result = 10 / 0; // Division par zéro
        } catch (ArithmeticException e) {
            System.out.println("Erreur : division par zéro !");
        }
    }
}

Bloc finally

Le bloc finally est exécuté quoi qu'il arrive, même si une exception est levée.


public class FinallyExample {
    public static void main(String[] args) {
        try {
            int result = 10 / 0;
        } catch (ArithmeticException e) {
            System.out.println("Erreur : division par zéro !");
        } finally {
            System.out.println("Bloc finally exécuté.");
        }
    }
}

Multi-catch

Depuis Java 7, il est possible de capturer plusieurs exceptions dans un seul bloc catch.


public class MultiCatchExample {
    public static void main(String[] args) {
        try {
            int[] array = new int[5];
            array[10] = 50; // ArrayIndexOutOfBoundsException
        } catch (ArrayIndexOutOfBoundsException | NullPointerException e) {
            System.out.println("Erreur : " + e.getMessage());
        }
    }
}

Propagation des exceptions

Lancer une exception avec throw

Vous pouvez lancer une exception explicitement avec le mot-clé throw.


public class ThrowExample {
    public static void main(String[] args) {
        try {
            throw new IllegalArgumentException("Argument invalide !");
        } catch (IllegalArgumentException e) {
            System.out.println(e.getMessage());
        }
    }
}

Déclarer une exception avec throws

Si une méthode ne gère pas une exception vérifiée, elle doit la déclarer avec throws.


import java.io.FileNotFoundException;
import java.io.FileInputStream;

public class ThrowsExample {
    public static void main(String[] args) {
        try {
            ouvrirFichier("fichier.txt");
        } catch (FileNotFoundException e) {
            System.out.println("Fichier non trouvé !");
        }
    }

    public static void ouvrirFichier(String chemin) throws FileNotFoundException {
        FileInputStream file = new FileInputStream(chemin);
    }
}

Création d'exceptions personnalisées

Vous pouvez créer vos propres exceptions en étendant la classe Exception ou RuntimeException.


class MonException extends Exception {
    public MonException(String message) {
        super(message);
    }
}

public class CustomExceptionExample {
    public static void main(String[] args) {
        try {
            throw new MonException("Ceci est une exception personnalisée !");
        } catch (MonException e) {
            System.out.println(e.getMessage());
        }
    }
}

Bonnes pratiques

  • Utilisez les exceptions uniquement pour des situations exceptionnelles.
  • Évitez de capturer des exceptions génériques comme Exception.
  • Ne laissez jamais un bloc catch vide.
  • Documentez les exceptions avec @throws dans les commentaires Javadoc.

Exercices pratiques

Voici quelques exercices pour pratiquer :

  1. Créez une méthode qui divise deux nombres et gère l'exception ArithmeticException.
  2. Écrivez un programme qui lit un fichier et gère l'exception FileNotFoundException.
  3. Créez une exception personnalisée pour gérer un âge invalide (par exemple, âge négatif).

Conclusion

Les exceptions sont un outil puissant en Java pour gérer les erreurs et les situations inattendues. En comprenant leur fonctionnement et en suivant les bonnes pratiques, vous pouvez écrire des programmes plus robustes et maintenables.
