Les List en Java

Introduction

En Java, une List est une interface qui représente une collection ordonnée d'éléments. Elle permet de stocker des éléments de manière séquentielle et offre des méthodes pour accéder, ajouter, supprimer et manipuler ces éléments. Les implémentations courantes de List sont ArrayList, LinkedList, et Vector.

Caractéristiques des List

  • Ordonnée : Les éléments sont stockés dans un ordre spécifique.
  • Accès par index : Vous pouvez accéder aux éléments par leur position (index).
  • Autorise les doublons : Une List peut contenir plusieurs fois le même élément.
  • Redimensionnable : La taille d'une List peut changer dynamiquement.

Méthodes principales de l'interface List

Voici quelques méthodes couramment utilisées de l'interface List :

  • add(E e) : Ajoute un élément à la fin de la liste.
  • add(int index, E e) : Ajoute un élément à un index spécifique.
  • get(int index) : Retourne l'élément à l'index spécifié.
  • remove(int index) : Supprime l'élément à l'index spécifié.
  • size() : Retourne le nombre d'éléments dans la liste.
  • contains(Object o) : Vérifie si la liste contient un élément spécifique.
  • clear() : Supprime tous les éléments de la liste.

Exemples d'utilisation

1. Création et manipulation d'une List

Voici un exemple simple d'utilisation d'une List avec ArrayList :

import java.util.ArrayList;
import java.util.List;

public class Main {
    public static void main(String[] args) {
        // Création d'une List de type ArrayList
        List<String> fruits = new ArrayList<>();

        // Ajout d'éléments
        fruits.add("Pomme");
        fruits.add("Banane");
        fruits.add("Cerise");

        // Accès aux éléments
        System.out.println("Fruit à l'index 1 : " + fruits.get(1)); // Banane

        // Suppression d'un élément
        fruits.remove("Banane");

        // Affichage de la liste
        System.out.println("Liste des fruits : " + fruits); // [Pomme, Cerise]
    }
}

Ce code affichera :

Fruit à l'index 1 : Banane
Liste des fruits : [Pomme, Cerise]

2. Parcourir une List avec une boucle for

Vous pouvez parcourir une List en utilisant une boucle for :

import java.util.ArrayList;
import java.util.List;

public class Main {
    public static void main(String[] args) {
        List<String> fruits = new ArrayList<>();
        fruits.add("Pomme");
        fruits.add("Banane");
        fruits.add("Cerise");

        // Parcours avec une boucle for
        for (int i = 0; i < fruits.size(); i++) {
            System.out.println("Fruit " + i + " : " + fruits.get(i));
        }
    }
}

Ce code affichera :

Fruit 0 : Pomme
Fruit 1 : Banane
Fruit 2 : Cerise

3. Utilisation de la méthode contains()

La méthode contains() permet de vérifier si un élément est présent dans la liste :

import java.util.ArrayList;
import java.util.List;

public class Main {
    public static void main(String[] args) {
        List<String> fruits = new ArrayList<>();
        fruits.add("Pomme");
        fruits.add("Banane");

        // Vérification de la présence d'un élément
        boolean contientPomme = fruits.contains("Pomme");
        System.out.println("Contient Pomme ? " + contientPomme); // true
    }
}

Ce code affichera :

Contient Pomme ? true

Conclusion

Les List en Java sont des collections ordonnées et flexibles qui permettent de stocker et de manipuler des éléments de manière efficace. Elles sont largement utilisées dans les programmes Java pour gérer des ensembles de données dynamiques. En maîtrisant les méthodes de base de l'interface List, vous pourrez manipuler des collections de données avec aisance.
