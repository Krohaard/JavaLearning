Introduction à Java

Qu'est-ce que Java ?

Java est un langage de programmation orienté objet, conçu pour être simple et portable. Il est largement utilisé pour le développement d'applications web, mobiles et embarquées. Java fonctionne sur la machine virtuelle Java (JVM), ce qui permet aux programmes Java d'être exécutés sur n'importe quelle plateforme supportant la JVM.

Installation de l'Environnement de Développement

Pour commencer à programmer en Java, suivez ces étapes :

  1. Installer le JDK (Java Development Kit) : Téléchargez et installez le JDK depuis le site officiel d'Oracle ou utilisez une distribution open-source comme OpenJDK.
  2. Configurer les Variables d'Environnement : Ajoutez le chemin vers le répertoire bin du JDK à votre variable d'environnement PATH.
  3. Installer un IDE (Integrated Development Environment) : Utilisez un IDE comme IntelliJ IDEA, Eclipse ou NetBeans pour écrire et gérer votre code Java.

Premier Programme Java : "Hello, World!"

Voici un exemple de programme Java simple qui affiche "Hello, World!" à l'écran :

public class HelloWorld { public static void main(String[] args) { System.out.println("Hello, World!"); } }

Exercices

Exercice 1

Écrivez un programme Java qui affiche votre nom à l'écran.

Exercice 2

Modifiez le programme "Hello, World!" pour qu'il affiche un message de bienvenue personnalisé en fonction de l'heure de la journée (par exemple, "Bonjour" le matin, "Bon après-midi" l'après-midi, etc.).
