Exercice Avancé sur les Interfaces en Java

Concept d'Interfaces Multiples

Dans cet exercice, nous allons explorer comment une classe peut implémenter plusieurs interfaces. Cela permet de définir des comportements multiples que la classe doit suivre.

Exercice : Système de Gestion de Bibliothèque

Crée un système de gestion de bibliothèque en utilisant les interfaces suivantes :

  • Interface `Empruntable` : Définir une méthode emprunter qui simule l'emprunt d'un livre.
  • Interface `Retournable` : Définir une méthode retourner qui simule le retour d'un livre.
  • Interface `Affichable` : Définir une méthode afficherDetails qui affiche les détails d'un livre.

Ensuite, crée une classe `Livre` qui implémente les trois interfaces ci-dessus. La classe doit avoir les attributs suivants :

  • titre : Le titre du livre.
  • auteur : L'auteur du livre.
  • disponible : Un booléen indiquant si le livre est disponible.

La classe `Livre` doit implémenter les méthodes des interfaces pour gérer l'emprunt, le retour et l'affichage des détails du livre.

Fonctions Utiles

Méthodes d'Interface :

  • default : Permet de fournir une implémentation par défaut pour une méthode dans une interface.
  • static : Permet de définir une méthode statique dans une interface.

Exemple de Solution

Voici un exemple de solution pour l'exercice :

interface Empruntable {
    void emprunter();
}

interface Retournable {
    void retourner();
}

interface Affichable {
    void afficherDetails();
}

class Livre implements Empruntable, Retournable, Affichable {
    private String titre;
    private String auteur;
    private boolean disponible;

    public Livre(String titre, String auteur) {
        this.titre = titre;
        this.auteur = auteur;
        this.disponible = true;
    }

    @Override
    public void emprunter() {
        if (disponible) {
            System.out.println("Le livre a été emprunté.");
            disponible = false;
        } else {
            System.out.println("Le livre n'est pas disponible.");
        }
    }

    @Override
    public void retourner() {
        System.out.println("Le livre a été retourné.");
        disponible = true;
    }

    @Override
    public void afficherDetails() {
        System.out.printf("Titre: %s, Auteur: %s, Disponible: %s\n", titre, auteur, disponible ? "Oui" : "Non");
    }
}

public class Main {
    public static void main(String[] args) {
        Livre livre = new Livre("1984", "George Orwell");
        livre.afficherDetails();
        livre.emprunter();
        livre.afficherDetails();
        livre.retourner();
        livre.afficherDetails();
    }
}
