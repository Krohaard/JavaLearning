Exercice Avancé sur les Interfaces en Java

Contexte

Dans cet exercice, tu vas créer un système de gestion de formes géométriques utilisant des interfaces pour définir des comportements communs.

Exercice : Système de Gestion de Formes

Crée un programme qui gère différentes formes géométriques (Cercle, Rectangle, Triangle) en utilisant des interfaces pour définir des comportements communs.

Exigences :

  1. Interface `Forme` : Définis une interface `Forme` avec les méthodes suivantes :
    • double calculerAire() : Calcule et retourne l'aire de la forme.
    • double calculerPerimetre() : Calcule et retourne le périmètre de la forme.
    • void dessiner() : Affiche une représentation textuelle de la forme.
  2. Classes Concrètes : Implémente les classes suivantes qui mettent en œuvre l'interface `Forme` :
    • Cercle : A un attribut rayon.
    • Rectangle : A des attributs longueur et largeur.
    • Triangle : A des attributs cote1, cote2, et cote3.
  3. Classe `GestionFormes` : Crée une classe qui gère une collection de formes. Elle doit avoir les méthodes suivantes :
    • void ajouterForme(Forme forme) : Ajoute une forme à la collection.
    • void dessinerFormes() : Dessine toutes les formes dans la collection.
    • double calculerAireTotale() : Calcule et retourne l'aire totale de toutes les formes dans la collection.
  4. Programme Principal : Dans la méthode main, crée plusieurs formes, ajoute-les à la collection, et utilise les méthodes de `GestionFormes` pour afficher les résultats.

ExpertTime : 2 heures
